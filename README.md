# TestMU-KaneAI-Certification
 
This repository contains test scenarios for the TestMu AI KaneAI certification.
 
## Scenario 1: Web Test – eCommerce Playground Product Search
 
Application URL: https://ecommerce-playground.lambdatest.io/
 
Steps:
1. Open the TestMu AI eCommerce Playground.
2. Search for a product (e.g. "iPhone") using the search bar.
3. Verify that the search results page displays relevant items matching the search term.
 
## Scenario 2: App Test – TestMu AI Sample App (Proverbial)
 
Android: Samsung Galaxy S25, Android 15
iOS: iPhone 16, iOS 18
 
Steps:
1. Open the TestMu AI Sample App.
2. Tap the "Text" button.
3. Verify that the text on the screen changes to "Proverbial".
4. Close the app.
